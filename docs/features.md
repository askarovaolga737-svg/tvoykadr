# ТвойКадр

## Цель проекта

Создать творческую платформу, где админ размещает рамки, картинки и видеоролики, а пользователи могут накладывать рамки на свои фото, генерировать картинки и видео по шаблонам, создавать мини-мультфильмы со своим лицом, генерировать презентации по теме, скачивать готовый контент и заказывать монтаж фото и видео.

## Основные возможности

### Наложение рамок на фото

- **Цель:** Пользователь может загрузить своё фото и наложить на него рамку, созданную админом
- **Описание:** Пользователь выбирает рамку из галереи, загружает своё изображение, видит предпросмотр результата и скачивает готовое фото с рамкой
- **Критерии приёмки:**
  - Пользователь видит галерею доступных рамок с превью
  - Пользователь может загрузить своё фото (JPG/PNG)
  - Пользователь видит предпросмотр фото с выбранной рамкой
  - Пользователь может скачать готовое изображение

### Генерация картинок по шаблонам

- **Цель:** Пользователь может выбрать шаблон картинки от админа, настроить текст/цвета и скачать результат
- **Описание:** Админ загружает шаблоны картинок (например, открытки, плакаты, обложки), пользователь выбирает шаблон, вводит свой текст и скачивает готовую картинку
- **Критерии приёмки:**
  - Пользователь видит галерею шаблонов картинок
  - Пользователь может ввести свой текст для шаблона
  - Пользователь видит предпросмотр готовой картинки
  - Пользователь может скачать результат

### Генерация видео по шаблонам

- **Цель:** Пользователь может выбрать видео-шаблон от админа, ввести свой текст и скачать готовое видео с наложенным текстом
- **Описание:** Админ загружает видео-шаблоны (например, поздравительные видео, заставки, клипы), пользователь выбирает шаблон, вводит свой текст и скачивает готовое видео с наложенным текстом
- **Критерии приёмки:**
  - Пользователь видит галерею видео-шаблонов с превью
  - Пользователь может ввести свой текст для шаблона
  - Пользователь может скачать готовое видео с наложенным текстом

### Создание мини-мультфильмов со своим лицом

- **Цель:** Пользователь может загрузить своё фото, выбрать мульт-шаблон и скачать готовый мини-мультфильм, где его лицо вставлено в анимированного персонажа
- **Описание:** Админ загружает мульт-шаблоны (анимированные сцены с персонажами, у которых область лица заменяема). Пользователь загружает своё фото, выбирает мульт-шаблон, видит предпросмотр и скачивает готовый мини-мультфильм
- **Критерии приёмки:**
  - Пользователь видит галерею мульт-шаблонов с превью
  - Пользователь может загрузить своё фото
  - Пользователь видит предпросмотр мультфильма со своим лицом
  - Пользователь может скачать готовый мини-мультфильм
  - Админ может загружать мульт-шаблоны в админ-панели

### Генерация презентаций по теме

- **Цель:** Пользователь может ввести тему и получить готовую презентацию с картинками и текстом
- **Описание:** Пользователь вводит тему презентации и количество слайдов. Система подбирает бесплатные фото из интернета по теме и создаёт стильно оформленные слайды с текстом. Также доступен вариант без фото — только цветовые блоки, иконки и градиенты. Пользователь может скачать готовую презентацию.
- **Критерии приёмки:**
  - Пользователь может ввести тему презентации
  - Пользователь может выбрать количество слайдов
  - Пользователь может выбрать стиль: с фото или без фото
  - Пользователь видит предпросмотр готовой презентации
  - Пользователь может скачать презентацию

### Заказ монтажа фото и видео

- **Цель:** Пользователь может отправить заказ на монтаж своего фото или видео с описанием работы
- **Описание:** Пользователь заполняет форму: загружает свой файл (фото или видео), пишет описание того, что нужно сделать, и отправляет заказ. Заказ появляется в админ-панели, где админ может просмотреть детали и отметить как выполненный
- **Критерии приёмки:**
  - Пользователь видит страницу с формой заказа монтажа
  - Пользователь может загрузить файл (фото или видео)
  - Пользователь может написать описание работы
  - Пользователь может отправить заказ
  - После отправки пользователь видит подтверждение
  - Админ видит новые заказы в админ-панели
  - Админ может просмотреть детали заказа
  - Админ может отметить заказ как выполненный

### Админ-панель

- **Цель:** Администратор может управлять всем контентом на платформе
- **Описание:** Админ имеет доступ к панели управления, где может добавлять, редактировать и удалять рамки, картинки-шаблоны, видео-шаблоны, мульт-шаблоны, а также просматривать и управлять заказами на монтаж. Файлы загружаются напрямую через форму, а не по ссылкам.
- **Критерии приёмки:**
  - Админ может войти в панель управления
  - Админ может загрузить новую рамку (изображение + название) через загрузку файла
  - Админ может загрузить новый шаблон картинки через загрузку файла
  - Админ может загрузить новый видео-шаблон через загрузку файла
  - Админ может загрузить новый мульт-шаблон через загрузку файла
  - Админ может удалить любой элемент контента
  - Админ видит список всего загруженного контента с превью
  - Админ видит список заказов на монтаж
  - Админ может просмотреть детали заказа
  - Админ может отметить заказ как выполненный

## Дополнительные заметки

- Стиль интерфейса: творческий и вдохновляющий — яркие акценты, плавные анимации, крупные превью контента
- Первая версия: наложение рамок на фото, генерация картинок по шаблонам, генерация видео по шаблонам, создание мини-мультфильмов, генерация презентаций, заказ монтажа, админ-панель
- Все данные хранятся в облачной базе данных
- Файлы загружаются напрямую через форму и сохраняются локально в папке /public/uploads
